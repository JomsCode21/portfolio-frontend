# Portfolio Frontend

The React and TypeScript client for Jhumari Job Galos’ developer portfolio. It contains the public portfolio and the protected administrator interface.

## Stack

- React 18
- TypeScript
- Vite
- React Router
- Axios

## Requirements

- Node.js 20 or newer
- A running Portfolio API (see the backend repository)

## Installation

```bash
npm install
```

Create `.env.local` in this folder:

```env
VITE_API_URL=http://localhost:5000/api
```

Use the deployed backend API URL instead when deploying the frontend.

## Scripts

```bash
npm run dev          # Start the Vite development server
npm run typecheck    # Check TypeScript types
npm run build        # Type-check and create a production build
npm run preview      # Preview the production build locally
npm run format       # Format code with Prettier
npm run format:check # Check formatting without changing files
```

## Routes

### Public

- `/` — portfolio home
- `/projects` — all projects
- `/projects/:slug` — individual project
- `/contact` — contact form

### Administrator

- `/admin/login`
- `/admin/dashboard`
- `/admin/projects`
- `/admin/skills`
- `/admin/experience`
- `/admin/education`
- `/admin/certifications`
- `/admin/messages`
- `/admin/settings`

The administrator routes require a valid JWT returned by the backend login endpoint. The token is stored in local storage and is automatically attached to protected API requests.

## Backend integration

All requests are centralised in `src/services/`. The client expects the API to expose its routes under the URL specified by `VITE_API_URL`, such as:

```text
GET  /api/settings
GET  /api/projects
POST /api/contact
POST /api/auth/login
```

Do not place database credentials, JWT secrets, or other private backend values in this repository or any `VITE_` variable.

## Deployment

Deploy the `dist` directory generated by `npm run build` to a static host such as Vercel, Netlify, or Cloudflare Pages. Configure `VITE_API_URL` in that host’s environment settings, and ensure the backend allows the deployed frontend origin through CORS.
